Displays

A cell can put an element on the page that stays live: it can change after the cell has run, and call the cell back when the reader uses it. That is displays, four functions in X_ocaml_lib:

  • display ~tag data shows a <tag> element under the cell, and update d data gives it new data; html is a display of HTML, built in.
  • callback f is a token that elements on the page can call, running f in the worker; string_of_token is what goes in their data.
  • require ~tag ~src loads the script that defines an element, once, if the page does not have it.

Displays and callbacks belong to their cell: run it again, or stop the toplevel, and they go. Everything below is OCaml in the cells, and four small elements of at most 32 lines of JavaScript.

Watch it compute updates while the cell runs

Until now, a cell showed nothing until each phrase finished. A display updated in a loop shows the computation as it goes.

(y *. y) <= 1. then incr inside; if i mod 100_000 = 0 then X_ocaml_lib.update estimate (Printf.sprintf "%s<p>After %d points, π ≈ <b>%.5f</b></p>" (bar (float i /. float total)) i (4. *. float !inside /. float i)) done

Controls that call OCaml no JavaScript

Elements in an HTML display with a data-callback token call back: an input with its value, a button when it is clicked. The plot is an SVG string, redrawn by the callbacks. The controls are in a display of their own, which is never replaced while you use it.

Your own element a canvas, in 32 lines

examples/elements/canvas.js draws circles and asks for the next frame; the physics is OCaml. It asks for a frame only once the last has been drawn, so a slow worker slows the animation rather than queueing up. Click the box to add a ball.

Random.float 4.; r = 6. +. Random.float 12.; colour = colours.(Random.int 6) } :: !balls let () = for _ = 1 to 12 do add (Random.float width) (Random.float (height /. 2.)) done let step () = List.iter (fun b -> b.vy <- b.vy +. 0.3; b.x <- b.x +. b.vx; b.y <- b.y +. b.vy; if b.y +. b.r > height then begin b.y <- height -. b.r; b.vy <- -. b.vy *. 0.93 end; if b.x -. b.r < 0. || b.x +. b.r > width then begin b.x <- Float.max b.r (Float.min (width -. b.r) b.x); b.vx <- -. b.vx end) !balls let running = ref true let canvas = X_ocaml_lib.display ~tag:"x-canvas" {|{"width":640,"height":320}|} let frame = ref "" and click = ref "" let draw () = let circle b = Printf.sprintf {|[%.1f,%.1f,%.1f,"%s"]|} b.x b.y b.r b.colour in X_ocaml_lib.update canvas (Printf.sprintf {|{"width":%g,"height":%g,"circles":[%s],"frame":%s,"click":%s}|} width height (String.concat "," (List.map circle !balls)) (if !running then !frame else "null") !click) let () = frame := X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun _ -> step (); draw ()); click := X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun p -> Scanf.sscanf p "%f %f" add; if not !running then draw ()); draw () let () = let toggle = X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun _ -> running := not !running; draw ()) in let shake = X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun _ -> List.iter (fun b -> b.vy <- b.vy -. 8. -. Random.float 6.; b.vx <- b.vx +. Random.float 6. -. 3.) !balls) in ignore (X_ocaml_lib.html (Printf.sprintf {|<button data-callback="%s">pause or play</button> <button data-callback="%s">shake</button> click the box to add a ball|} toggle shake))

A binary search tree, drawn by Mermaid through a 17-line element. Keep inserting bigger numbers and watch it lean.

let () = X_ocaml_lib.require ~tag:"x-mermaid" ~src:"examples/elements/mermaid.js" type tree = Leaf | Node of tree * int * tree let rec insert x = function | Leaf -> Node (Leaf, x, Leaf) | Node (l, y, r) as t -> if x < y then Node (insert x l, y, r) else if x > y then Node (l, y, insert x r) else t let rec height = function Leaf -> 0 | Node (l, _, r) -> 1 + max (height l) (height r) let rec size = function Leaf -> 0 | Node (l, _, r) -> size l + 1 + size r let rec lines = function | Leaf -> [] | Node (l, x, r) -> let edge = function | Node (_, y, _) -> [ Printf.sprintf " n%d((%d)) --> n%d((%d))" x x y y ] | Leaf -> [] in Printf.sprintf " n%d((%d))" x x :: edge l @ edge r @ lines l @ lines r let diagram t = String.concat "\n" ("graph TD" :: lines t) let tree = ref (List.fold_left (fun t x -> insert x t) Leaf [ 50; 30; 70; 20; 40; 60; 80 ]) let shown = X_ocaml_lib.display ~tag:"x-mermaid" (diagram !tree) let stats = X_ocaml_lib.html "" let describe () = X_ocaml_lib.update stats (Printf.sprintf "%d numbers, %d levels deep" (size !tree) (height !tree)) let () = describe (); let add = X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun how -> let x = if how = "big" then 100 + size !tree else Random.int 100 in tree := insert x !tree; X_ocaml_lib.update shown (diagram !tree); describe ()) in ignore (X_ocaml_lib.html (Printf.sprintf {|<button data-callback="%s" data-payload="random">insert a random number</button> <button data-callback="%s" data-payload="big">insert a bigger one</button>|} add add))

Sound Web Audio

Melodies composed in OCaml, played by a 28-line element. The walks are random: ask for new ones.

let () = X_ocaml_lib.require ~tag:"x-tone" ~src:"examples/elements/tone.js" (* A MIDI note number as a frequency: 69 is the A above middle C. *) let hz n = 440. *. (2. ** (float (n - 69) /. 12.)) let major = [| 0; 2; 4; 5; 7; 9; 11 |] and minor = [| 0; 2; 3; 5; 7; 8; 10 |] (* The n-th note of the scale, going up through the octaves. *) let degree scale root n = root + (12 * (n / 7)) + scale.(n mod 7) (* A melody by a random walk on the scale, ending at home. *) let walk scale root length = let rec go n pos acc = if n = 0 then List.rev ((hz (degree scale root 7), 0.6) :: acc) else let step = [| -2; -1; -1; 1; 1; 2; 3 |].(Random.int 7) in let pos = max 0 (min 13 (pos + step)) in let length = if Random.int 4 = 0 then 0.36 else 0.18 in go (n - 1) pos ((hz (degree scale root pos), length) :: acc) in go length 7 [] let json label notes = Printf.sprintf {|{"label":%S,"notes":[%s]}|} label (String.concat "," (List.map (fun (f, s) -> Printf.sprintf "[%.2f,%.2f]" f s) notes)) let scale_run scale root = List.init 8 (fun i -> (hz (degree scale root i), 0.2)) @ [ (0., 0.2) ] @ List.init 8 (fun i -> (hz (degree scale root (7 - i)), 0.2)) let tunes = [ ("C major, up and down", scale_run major 60); ("A minor, up and down", scale_run minor 57); ("a walk in D major", walk major 62 24); ("a walk in E minor", walk minor 64 24) ] let players = List.map (fun (label, notes) -> X_ocaml_lib.display ~tag:"x-tone" (json label notes)) tunes let () = let again = X_ocaml_lib.string_of_token @@ X_ocaml_lib.callback (fun _ -> X_ocaml_lib.update (List.nth players 2) (json "a walk in D major" (walk major 62 24)); X_ocaml_lib.update (List.nth players 3) (json "a walk in E minor" (walk minor 64 24))) in ignore (X_ocaml_lib.html (Printf.sprintf {|<button data-callback="%s">new walks</button>|} again))

x-ocaml knows nothing about any of these elements. It places each display under its cell, gives it its data, carries its callbacks to the worker, and takes it away when the cell runs again.
